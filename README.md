# Piper + Alicia 本机遥操界面

本机浏览器界面，用 Alicia-DL 示教臂控制 PiPER 单臂和夹爪。分别检测两臂后，按“准备遥操”自动记录软件起点并做只读检查，再按“启动遥操”或“退出遥操”。启动与退出按钮和关节状态同屏显示；横条上的圆点表示当前角度，接近范围边界 1.5° 或超出时整条变红。只监听 `127.0.0.1`，不修改硬件零点。

## 安装与打开

在连接两臂的**本机**运行（建议 Python 3.12）：

```bash
git clone https://github.com/Kostov0129/Piper_Alicia_teleoperation.git
cd Piper_Alicia_teleoperation
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
env -u PYTHONPATH .venv/bin/python interface.py
```

然后在同一台电脑的浏览器打开 `http://127.0.0.1:8769/`，不要直接打开 `index.html` 文件。关闭网页时，程序会停止遥操与关节监看，并在短暂等待页面重载后退出本机服务；页面意外断开超过 5 秒也会退出。重新使用时再运行上面的 `interface.py` 命令。Alicia 默认串口 `/dev/ttyACM0`，PiPER 默认 CAN 接口 `can0`；如需修改，展开“连接设置”。PiPER 当前使用 V2 SDK，已在 S-V1.8-5 固件上测试。

先分别点击“检测 Alicia”和“检测 PiPER”。把两臂摆到舒适的对应姿态、空夹并停稳，点击“准备遥操”；准备完成后勾选现场监护，点击“启动遥操”。只读检查若有异常会拒绝启动。遥操持续到点击“退出遥操”；若页面心跳中断超过 8 秒，程序也会停止跟随并尝试保持 PiPER 当前姿态。网页“退出遥操”**不是硬件急停**；现场需要有人监护并可使用 PiPER 实体急停。程序运行后 PiPER 可能保持 CAN 控制与电机使能，要手动搬动时先按厂家流程切回示教模式。

## 映射与范围

六轴增量映射取自六组人工匹配姿态，配置见 `matched_pose_trial_mapping_wider.json`。当前相对起点范围 ±40°、PiPER 速度档位 100%、最大指令速率 45°/秒，另有绝对关节限位、反馈过期、跟踪误差和指令超前量保护。它是**试验映射**，尚未用独立姿态验证末端精度，不适合无人监护或直接用于采摘。

准备前，角度表显示 PiPER 的保守绝对限位；准备后，范围缩为该限位与所选起点行程的交集。Alicia 范围是经映射后对应的有效区间，**不是 Alicia 硬件限位**。没有新鲜反馈时当前角度显示“—”，不把上次起点当作实时角度。

如果 J2/J3 在未达到 PiPER 自身限位前就停止跟随，可勾选“扩展 J2/J3 行程”并重新点击“准备遥操”。这只把 J2 的起点行程从 ±40° 扩到 ±90°、J3 从 ±40° 扩到 ±120°；其他四轴不变，原有 PiPER 保守绝对限位、SDK 关节限位、速度和反馈保护继续生效。扩展模式仍是未独立验证的试验设置，使用时保持现场监护并留意桌面、线缆和自碰撞。

本机软件起点、实时反馈和界面运行日志保存在 `runtime/`；SDK 还可能生成 `logs/`。两者均由 `.gitignore` 排除，不会上传到 GitHub。每次更换姿态或再次启动，都要重新点击“准备遥操”。
